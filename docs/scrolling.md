# Прокрутка Markdown

## Ошибка

В версии 0.1.0 длинный документ открывался под кнопками скачивания, но колесо мыши
не прокручивало текст. Воспроизведено в BB 0.46.1: высота области просмотра — 803 px,
высота содержимого — более 8200 px, после прокрутки `scrollTop` оставался равен нулю.

Плагин помещал `<Original />` в контейнер `min-h-0 flex-1`. Его вычисленное
`overflow-y` было `visible`, поэтому контейнер не создавал область прокрутки.
Внешняя панель BB с `overflow-hidden` обрезала выходящий за границы документ.

## Исправление в 0.1.1

Контейнеру `<Original />` в `app.tsx` добавлен `overflow-y-auto`:

```tsx
<div className="min-h-0 flex-1 overflow-y-auto"><Original /></div>
```

Высота контейнера по-прежнему ограничивается оставшимся местом в панели.
Прокручивается документ, а кнопки скачивания остаются над ним. JavaScript-обработчики
колеса и дополнительные способы просмотра не добавляются.

## Браузерная проверка

jsdom не рассчитывает геометрию страницы, поэтому проверка выполняется Playwright
в настоящем BB с установленной проверяемой версией плагина.

1. Запустите BB и откройте в треде длинный Markdown-файл, например этот документ.
   В панели должен использоваться просмотрщик **Markdown со скачиванием**.
2. Установите браузер для Playwright:

   ```sh
   npm ci
   npx playwright install --with-deps chromium
   ```

3. Передайте URL треда и имя уже открытого файла:

   ```sh
   npm run test:scroll -- http://127.0.0.1:3000/threads/THREAD_ID scrolling.md
   ```

   Используйте адрес своего BB. Он должен быть доступен браузеру без дополнительного
   входа. Скрипт не переносит учётные данные пользователя.

Скрипт проверяет, что документ длиннее области просмотра, прокручивает его колесом
мыши и требует увеличения `scrollTop`. Дополнительно проверяется, что кнопки остаются
на прежнем месте. Проверка повторяется на ширине 1440 и 900 px. Это проверка раскладки
в Chromium с двумя размерами окна; нативные жесты iOS она не проверяет.

До исправления скрипт завершается с ошибкой `Markdown does not scroll` и метриками
контейнера. Для версии 0.1.1 ожидаются две строки `PASS`. Проверка запускается отдельно
от CI, поскольку ей необходим работающий BB и открытый файл.

Проверено 2026-10-23 в BB 0.46.1: исходная версия не прокручивалась, исправленная
проходит проверку на ширине окна 1440 и 900 px. Кнопки скачивания сохраняют своё
положение. Также прошли 52 существующих теста, проверка TypeScript и сборка плагина.
Отдельно проверены прокрутка в **Preview / Raw** и обе кнопки скачивания:
имя и байты исходного Markdown сохранены, ZIP содержит тот же файл без изменений.

Также вручную проверьте прокрутку после переключения **Preview / Raw** и скачивание
исходного файла и ZIP. Автотест прокрутки не переключает эти режимы и не скачивает файлы.
